FAQ

คำถามที่พบบ่อย

แพลตฟอร์มรองรับแนวคิด Zero Trust อย่างไร?

ด้วยการบังคับใช้สิทธิ์ขั้นต่ำที่สุดกับทุกตัวตนบนทุกอุปกรณ์ ให้สิทธิ์เฉพาะช่วงเวลาที่จำเป็น และเฝ้าระวังอย่างต่อเนื่องเพื่อปรับการควบคุมตามระดับความเสี่ยง

ปกป้องตัวตนที่ไม่ใช่มนุษย์ (เครื่องจักรและเอเจนต์ AI) ได้ไหม?

ได้ ครอบคลุมการค้นหา การวิเคราะห์ความเสี่ยง การจัดการความลับ และการตรวจสอบย้อนหลังสำหรับเครื่องจักรและเอเจนต์ AI ทุกประเภท

เชื่อมต่อกับเครื่องมือที่ใช้อยู่เดิมได้หรือไม่?

รองรับอินทิเกรชันสำเร็จรูปและ API สำหรับระบบคลาวด์ ไปป์ไลน์ CI/CD และเครื่องมือ SOC ที่นิยมใช้

เริ่มต้นใช้งานใช้เวลานานเท่าไร?

โดยทั่วไปเริ่มเห็นผลภายในไม่กี่สัปดาห์ เราช่วยวางแผนและติดตั้งแบบเป็นขั้นตอนตามลำดับความเสี่ยงขององค์กร
